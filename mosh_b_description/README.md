# mosh_b_description

Robot description for **mosh_b**, generated by URDF Forge.
REP 103 conventions: Z-up, metres, kilograms, radians.

## Build

```bash
cd ~/ros2_ws/src && cp -r /path/to/mosh_b_description .
cd ~/ros2_ws && rosdep install --from-paths src -y --ignore-src
colcon build --packages-select mosh_b_description && source install/setup.bash
```

## Run

`ros2 launch mosh_b_description display.launch.py` shows the model in RViz with joint sliders.

| Target | Distribution | Simulator launch |
| --- | --- | --- |
| `jazzy-harmonic` | ROS 2 Jazzy · Gazebo Harmonic | `ros2 launch mosh_b_description gazebo_jazzy-harmonic.launch.py` |

Pick a world with `world:=<file>`, for example `ros2 launch mosh_b_description gazebo_jazzy-harmonic.launch.py world:=room.sdf`.

## Layout

- `urdf/mosh_b.urdf.xacro`: the source of truth. `xacro mosh_b.urdf.xacro sim:=<target>` (default `jazzy-harmonic`).
- `urdf/mosh_b.<target>.urdf`: pre-expanded URDF per target, for tools that cannot run xacro.
- `sdf/mosh_b/`: standalone SDF model.
- `meshes/`: binary STL meshes.
- `config/controllers.yaml`: ros2_control controllers. `config/gz_bridge_<target>.yaml`: ROS <-> Gazebo topics.
- `worlds/`: Gazebo worlds. `empty.sdf` is the default. `room`, `maze`, `office`, `tb3_sandbox`, `depot` and `warehouse` came from the horizon_robot project. `depot` and `warehouse` download models from Gazebo Fuel the first time they load, so they need internet then.

## Notes

- Mesh URIs use `package://mosh_b_description/...`. The launch files add the install share
  directory to the simulator's resource path so Gazebo can resolve them.
- Inertias were integrated over the mesh geometry for a solid of uniform density. Check any link
  the editor flagged as not watertight.
